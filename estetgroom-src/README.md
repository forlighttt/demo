# Сайт груминг-салона ЭстетГрум

Многостраничный сайт, связанный с онлайн-записью bimassist (организация 581).

## Как это работает
- `sync.py` раз в сутки забирает из открытого API bimassist услуги, цены, длительность, мастеров, рейтинг и отзывы и пишет их в `data.json`. Если bimassist недоступен, остаются прежние данные.
- `build.py` собирает из `data.json` и `config.json` готовые страницы в `dist/`: главная, груминг собак, груминг кошек, мастера, отзывы, контакты, плюс 404, robots.txt, sitemap.xml (когда задан домен) и CNAME.
- Кнопки «Записаться» открывают форму записи bimassist поверх сайта. Рядом всегда есть ссылка «В новой вкладке».
- GitHub Actions (`.github/workflows/deploy.yml`) запускает синхронизацию и сборку каждый день в 06:00 по Москве и при каждом пуше, и публикует сайт на GitHub Pages.

## Ручные настройки: `config.json`
- `domain`: домен клиента, например `estetgroom.ru`. Появятся CNAME, canonical и sitemap.
- `yandex_metrika_id`: номер счётчика Метрики. Цели: `booking_open` (открыл запись) и `phone_click` (нажал на телефон).
- `socials`: ссылки на WhatsApp, Telegram, ВК. Пустые не показываются.

## Запуск у себя
```
python sync.py   # обновить данные (нужен доступ в интернет)
python build.py  # собрать в dist/
```

## Публикация
1. Создать репозиторий на GitHub, залить содержимое этой папки в ветку main.
2. Settings → Pages → Source: GitHub Actions.
3. Домен: в DNS у регистратора A-записи на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 и CNAME `www` на `ЛОГИН.github.io`. Затем вписать домен в `config.json` и в Settings → Pages → Custom domain, включить Enforce HTTPS.

## Что заменить, когда клиент пришлёт материалы
- Фото салона: блок `.photo` на главной.
- Фото работ: блок «До и после» (`gallery`).
- Фото мастера Марины загружается в bimassist и подтянется само.
